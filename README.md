Innovation DNA

«Transforming ideas into innovation.»

Innovation DNA is an AI-powered student innovation ecosystem designed to help students, faculty, mentors, and administrators collaborate on projects, learning, hackathons, mentorship, and startup development through a single platform.

Built for Dhaanish Ahmed College of Engineering, Chennai, the platform aims to simplify the complete innovation journey—from learning a new skill to building projects, participating in hackathons, and eventually launching startups.

---

Overview

Students often switch between multiple websites to find learning resources, hackathons, internships, mentors, project collaborators, and startup opportunities.

Innovation DNA brings these experiences together into one unified platform with a clean, modern, and premium user experience.

The current version focuses on a polished frontend experience using realistic mock data while keeping the architecture ready for backend integration.

User Roles

The platform currently supports separate experiences for:

- Student
- Faculty
- Mentor
- Dean
- Administrator

Each role only sees the navigation, dashboard, and tools relevant to their responsibilities.

Design Philosophy

Innovation DNA is designed around a simple principle:

«Innovation should be accessible, collaborative, and enjoyable.»

The interface focuses on clarity, consistency, and meaningful interactions rather than unnecessary visual complexity.
