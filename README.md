# Innovation Compass

Build a premium frontend-only web application for Innovation DNA, an AI-powered student innovation and startup ecosystem for Dhaanish Ahmed College of Engineering, Chennai.

This is not a cyberpunk, robotic, neon-heavy, or gamer-style UI.
The design direction must be warm, elegant, premium, academic, and advanced, with a cream-based luxury palette and extremely polished UX.

PROJECT GOAL

Innovation DNA helps students:

log in by role

explore learning resources

track projects

discover hackathons and internships

connect with mentors

access AI guidance

explore startup ideas

receive notifications

manage their innovation journey in one platform

The final product should feel like a top-tier modern campus innovation ecosystem, not a generic student portal.
